Can a player's psychological profile predict football ability?

A data pipeline from raw player data → Supabase → SAS Viya modelling → this page.

1. The question

Coaches have long argued that what happens between a footballer's ears — composure under pressure, aggression, vision, decision speed — matters as much as raw athleticism. This project asks a measurable version of that question: how much of a player's overall ability can be explained by their psychological / mentality profile alone?

2. The data

The modelling base is the FIFA 22 complete player dataset (~19,000 players). For each player it records an overall ability rating (0–99) alongside a set of mentality attributes that map closely onto psychological constructs:

  • Composure — emotional control under pressure
  • Aggression — intensity / assertiveness
  • Vision — anticipation & awareness
  • Positioning — spatial reasoning
  • Penalties — performance in high-stakes moments
  • Interceptions — reading the game
  • Reactions — decision speed / game intelligence

Honest caveat: these are scout-rated video-game attributes, not clinical psychometric tests. They are a proxy for a psychological profile, and results should be read as "how well do rated mental attributes track ability", not as the output of a validated personality instrument.

3. What the research literature says

Real psychometric studies of footballers exist but rarely release individual-level data. The consistent findings from that literature give us a benchmark for interpreting our model:

  • A meta-analysis of 4,101 athletes found conscientiousness and extraversion positively correlated with athletic performance (PMC10813302).
  • In NCAA soccer, neuroticism + conscientiousness explained ~23% of coach rating variance; conscientiousness alone ~8% of game-statistic variance.
  • A study of women's football showed psychological factors add predictive power beyond physical ability (PMC10090955).

The theme: psychological traits are real but partial predictors. We should expect our mentality profile to explain a meaningful share of ability — not all of it.

4. A crash course in the models

We fit two different kinds of statistical model and compare them. Here's what each one does, in plain language.

Linear regression (OLS)

Ordinary Least Squares draws the straight-line relationship that best predicts ability from the seven mental attributes. It assumes each attribute contributes a fixed amount: "every extra point of reactions adds about half a point of overall ability", and adds those contributions up. The line is chosen to make the squared prediction errors as small as possible.

R² (R-squared)
The share of the variation in ability the model explains, from 0 (useless) to 1 (perfect). R² = 0.79 means 79% of why players differ in ability is captured by the profile; the other 21% is everything the model can't see.
RMSE
Root-mean-square error — the typical size of a prediction miss, in rating points. Lower is better.
Standardized coefficient (β)
Each attribute on a common scale so they're comparable. A bigger bar = a stronger independent pull on predicted ability. These can be negative: once reactions is accounted for, a higher positioning score can be associated with slightly lower overall — a sign the attributes overlap (multicollinearity), so the model splits credit between them.
p-value
How confident we are an effect is real and not noise. Tiny p-values (<0.001) mean the relationship is statistically solid — easy to achieve here because we have ~19,000 players.

Decision tree

A decision tree takes the opposite approach: instead of one straight line, it repeatedly splits players into groups with yes/no questions ("is reactions above 70?", then "is composure above 60?") and predicts the average ability within each final group. This lets it capture nonlinear patterns and interactions a straight line misses — which is why it usually fits a bit better.

Why this isn't a random forest: a random forest averages hundreds of trees and is the usual go-to, but that procedure isn't licensed on this SAS Viya instance. We use a single tree (PROC HPSPLIT) as the nonlinear comparison. Also note both R² values here are in-sample (measured on the same data used to fit), so the tree's edge is partly genuine flexibility and partly a tree's tendency to fit the training data closely — read the gap as "nonlinearity helps", not "the tree is twice as good".

5. The pipeline

  1. Ingest — raw CSV cleaned in Python, loaded into a Supabase Postgres table (players).
  2. Model — SAS Viya reads the table over the Supabase REST API and fits both models (PROC REG and PROC HPSPLIT) with overall as the explained variable.
  3. Persist — SAS Viya POSTs fit statistics, coefficients, per-position results and predictions back into Supabase.
  4. Visualize — this page reads those result tables live from Supabase and renders everything below.

7. What it tells us

Interpretation will populate once results load…

Read alongside section 3: if a profile of rated mental attributes explains a large share of ability, it supports the coaching intuition that the mental side of the game is deeply entangled with overall quality — while the unexplained remainder is the room left for physique, technique and everything a mentality score cannot capture.

8. Reproduce it

Everything is open source. See the GitHub repository:

pip install -r scripts/requirements.txt
python scripts/download_data.py
python scripts/run_schema.py          # create Supabase tables
python scripts/load_to_supabase.py    # load players
# then run sas/model.sas on SAS Viya: pulls data, fits OLS + tree,
# writes results, coefficients, predictions and per-position fit back to Supabase
